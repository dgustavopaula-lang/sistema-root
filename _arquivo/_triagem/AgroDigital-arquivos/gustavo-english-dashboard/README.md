# Gustavo English Dashboard

Projeto simples criado com HTML, CSS e JavaScript para praticar no VS Code.

## Estrutura

- `index.html`: página principal
- `css/style.css`: aparência do projeto
- `js/script.js`: interações e funções
- `assets/images`: pasta para imagens

## Como abrir

1. Extraia a pasta.
2. Abra o VS Code.
3. Clique em **File > Open Folder**.
4. Escolha a pasta `gustavo-english-dashboard`.
5. Abra o arquivo `index.html`.
6. Clique duas vezes no arquivo ou use uma extensão como Live Server.

Também é possível abrir o `index.html` diretamente no navegador.
