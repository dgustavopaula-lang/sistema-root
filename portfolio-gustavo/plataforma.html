// fundamentos

Por que GPS.dev?

Uma plataforma construída com princípios claros — leve, independente e preparada para crescer.

Stack leve

HTML, CSS e JavaScript puro. Sem React, sem Node, sem build. Roda em qualquer máquina.

Dados do cliente

Os dados pertencem ao contratante. Sem lock-in de plataforma, sem dependência de terceiros.

IA integrada

Cada vertical tem módulo de IA para análise, sugestão e automação via Anthropic Claude.

Modular

O cliente contrata o que precisa. Cada módulo é independente e cresce com o negócio.

SaaS recorrente

Mensalidade fixa por vertical. Sem custo de servidor para o cliente, sem surpresa no boleto.

GitHub Pages

Hospedagem gratuita, estável e pública. Sem contrato com provedor de hosting.

Fases da plataforma

Do produto entregue à escala com múltiplos clientes.

FASE 01

Produto

Sistemas funcionando por vertical. Hotelaria entregue e em produção. Farmácia em desenvolvimento.

FASE 02

Multitenancy

Autenticação por cliente, dados isolados via Supabase. Cada negócio acessa apenas os seus dados.
