# Sistema Root

Arquitetura-base (single-file) usada como fundação para os sistemas leves desenvolvidos pela **GPS.dev**.

## O que é

Template padrão em HTML/CSS/JS de arquivo único, reutilizado como ponto de partida para sistemas de gestão sob medida (hotelaria, imobiliário, agro, saúde, varejo etc.).

## Stack

HTML / CSS / JS puro — sem dependência de build.

## Identidade visual

- Fundo: `#0f172a`
- Destaque: `#F97316`
- Ícones: Remix Icons

## Status

🟢 Em uso ativo como base de novos projetos
