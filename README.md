# 🌐 Sistema Root — GPS.dev

> **Central Hub & Starter Kit** do ecossistema de micro-sistemas web leves para gestão de pequenos e médios negócios.

---

## 📌 Sobre o Projeto

O **Sistema Root** funciona como a matriz técnica e arquitetural da **GPS.dev**. Ele estabelece os padrões de interface, componentes base e arquitetura enxuta (HTML5, CSS3 e JavaScript puro) para prototipar e implantar dashboards sob medida com agilidade.

Esta base alimenta soluções como dashboards para clínicas, farmácias, hotelaria e gestão operacional.

---

## 🚀 Módulos & Projetos Derivados

* 🩺 **Saúde:** Gestão de prontuários e agendamentos (`sistema-clinica-saude`)
* 💊 **Farmácia:** Controle de estoque e movimentação (`sistema-farmacia`)
* 🏨 **Hotelaria:** Retenção de hóspedes via QR Code (`hotel-dashboard`)
* 🌾 **Agro:** Plataformas de inteligência operacional agrícola (`AgroDigital` / `Pipe`)

---

## 🛠️ Tecnologias Principais

* **Interface:** HTML5 Semântico, CSS3 Moderno (Flexbox/Grid)
* **Lógica:** JavaScript ES6+ (Design modular e manipuladores de estado)
* **Padrão:** Código leve, responsivo e de fácil manutenção
